# Прогноз месячного оборота: прозрачные базовые стратегии

Модуль прогнозирует оборот после строк отмен, в GBP. Это не прибыль и не прогноз денежных поступлений. Используется публичный набор **UCI Online Retail II**: [Chen, D. (2012), DOI 10.24432/C5CG6D](https://doi.org/10.24432/C5CG6D), CC BY 4.0.

## Воспроизведение

Из папки проекта после расчёта SQL-витрин командой `python run.py`:

```sh
python forecast.py --tests-only
python forecast.py --input results/monthly.csv
```

Модуль использует только стандартную библиотеку Python 3.10+. Выходы по умолчанию:

- `results/forecast.json` — история, сравнение трёх стратегий, ошибки каждого фолда и итоговый прогноз.
- `results/forecast_backtest.csv` — 18 строк: три стратегии × шесть месяцев проверки.

Допустимы `--output` и `--backtest-output` для альтернативных путей. Некорректный ввод и неуспешные тесты завершают процесс с ненулевым кодом.

## Какие данные использованы

Входной CSV содержит ровно 24 полных месяца: декабрь 2009 — ноябрь 2011. Колонки: `month,gross_pence,cancel_pence,net_pence,orders`. Суммы хранятся в целых пенсах; `net_pence = gross_pence - cancel_pence`. Отрицательный оборот при отменах допустим. Отсутствующие месяцы не подменяются нулями, повторяющиеся ключи отклоняются.

**Неполный декабрь 2011 исключён.** Его данные не используются ни для обучения, ни как фактическое значение в оценке прогноза декабря. Прогноз остаётся проверяемой исторической постановкой «что было доступно на конец ноября 2011», а не прогнозом современного бизнеса.

## Стратегии

| ID | Правило прогноза следующего месяца |
| --- | --- |
| `last_month` | Оборот последнего полного месяца |
| `mean_3` | Среднее трёх последних полных месяцев |
| `seasonal_12` | Оборот того же календарного месяца предыдущего года |

Среднее считается через точную рациональную арифметику и округляется до ближайшего пенса. Все три стратегии дают точечный прогноз. У них нет подбираемых коэффициентов или внешних признаков; это понятные ориентиры для сравнения с более сложной моделью.

## Walk-forward backtest без подглядывания

Последние шесть полных месяцев — **июнь–ноябрь 2011** — последовательно используются как целевые месяцы. Прогноз всегда строится на один месяц вперёд.

| Фолд | Обучение заканчивается | Прогнозируется |
| --- | --- | --- |
| 1 | май 2011, 18 месяцев | июнь 2011 |
| 2 | июнь 2011, 19 месяцев | июль 2011 |
| 3 | июль 2011, 20 месяцев | август 2011 |
| 4 | август 2011, 21 месяц | сентябрь 2011 |
| 5 | сентябрь 2011, 22 месяца | октябрь 2011 |
| 6 | октябрь 2011, 23 месяца | ноябрь 2011 |

На каждом шаге расчёту передаётся только доступный префикс истории. Фактическое значение предыдущего фолда входит в обучение следующего: к этому моменту месяц уже завершён. Это последовательная оценка месячного процесса, а не одновременный шестимесячный прогноз.

Ошибки хранятся по каждому месяцу и стратегии:

- `error_gbp = actual_gbp - prediction_gbp`; положительная ошибка означает недопрогноз.
- `absolute_error_gbp = abs(error_gbp)`.
- `MAE = mean(abs(actual - prediction))`, в GBP.
- `WAPE = sum(abs(actual - prediction)) / sum(abs(actual))`. Модуль использует абсолютные фактические суммы и при нулевом знаменателе возвращает `null`, а не 0 или бесконечность.

## Выбор стратегии и его ограничения

`recommended_id` — стратегия с минимальной MAE на этих шести фолдах. Для выбора сравнивается целая сумма абсолютных ошибок в пенсах до округления отображаемой MAE. При точном равенстве применяется фиксированный порядок: `last_month`, затем `mean_3`, затем `seasonal_12`.

**Те же шесть месяцев используются и для выбора, и для показанных метрик. Это не независимая оценка выбранной стратегии.** Значение `selection.independent_selected_model_evaluation` равно `false`; `same_folds_used_for_selection` равно `true`. Оно не означает, что выбранный метод гарантированно лучше на будущих данных. Для независимой проверки нужен следующий полностью наблюдаемый период, которого в доступном наборе нет.

После сравнения каждая стратегия отдельно использует все 24 полных месяца, до ноября 2011 включительно, для точечного прогноза **декабря 2011**. Итог показан для всех стратегий, а не только победителя.

Интервалы не выдаются как калиброванные: шести ошибок недостаточно для надёжной оценки хвостов распределения. Не учтены изменение цен, маркетинг, ассортимент, запасы и структурные изменения. Два года истории также дают мало примеров сезонного поведения.

## Контракт JSON для интерфейса

```text
meta: {currency, source, source_url, training_start, training_end,
       history_months, backtest_folds, horizon_months, target,
       built_at_utc, monthly_csv_sha256}
forecast_month: "2011-12"
models: [{id, label, mae_gbp, wape, forecast_gbp,
          absolute_error_pence, wape_denominator_pence}]
backtest: [{month, train_through, train_months, actual_gbp,
            predictions: {model_id: prediction_gbp},
            errors_gbp: {model_id: actual_minus_prediction},
            absolute_errors_gbp: {model_id: absolute_error}}]
history: [{month, net_gbp}]
recommended_id: "last_month" | "mean_3" | "seasonal_12"
recommendation_label: string
selection: {metric, period_start, period_end, same_folds_used_for_selection,
            independent_selected_model_evaluation, tie_break_order, explanation}
limitations: [string, ...]
```

`wape` хранится как доля: интерфейс умножает её на 100 для отображения процента. `null` должен показываться как «не определено». На графике декабря нельзя рисовать фактический оборот, которого здесь нет. Сравнение моделей и подпись о подборе на тех же шести месяцах должны находиться рядом.

## Проверки

Тесты проверяют корректные лаги, среднее с округлением до пенса, расчёт на линейном примере с известным ответом, обучение только на прошлом, отсутствие утечки при изменении будущих месяцев, знаменатель WAPE при отрицательных значениях, нулевой знаменатель, равенство стратегий, отклонение неполного декабря/пропусков/дубликатов, нечисловых сумм и нарушения денежного баланса. Отдельно проверен месяц только с отменами.

Численные результаты реального набора записываются в JSON/CSV самим скриптом; документ не содержит вручную введённых значений прогноза.
