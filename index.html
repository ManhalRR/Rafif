Клиентов возвращаются в следующий месяц

Взвешенное M1 для когорт января–октября. Следующий шаг — сравнить зрелые когорты и проверить полноту CustomerID: он отсутствует в 24,9% исходных строк. Эти операции входят в оборот, но не в удержание. Называть M1 «низким» без ориентира нельзя.

ОТМЕНЫ / ГРАНИЦЫ ВЫВОДА

£616 899 отмен требуют проверки причин

Сумма отмен составляет 6,70% положительных продаж. Это отношение денежных сумм, а не доля возвращённых заказов. Следующий шаг — связать отмены с исходными заказами и причинами; в текущих данных такой надёжной связи нет. Прибыль и ROI не рассчитываются без затрат.

Источники и право на публикацию

Продажи: Chen, D. (2015), UCI Online Retail, лицензия CC BY 4.0. Данные A/B-теста синтетические, seed 20261027. Внутренние данные компаний не используются.

Качество данных и ограничения
  • Исходно 541 909 строк; исключены строки без положительной цены.
  • Пропуски CustomerID исключены из когорт, но сохранены в обороте.
  • Совпадающие строки сохранены: надёжного ID строки в источнике нет. Чувствительность итогов к дубликатам рассчитана отдельно.
  • Неполный декабрь 2011 исключён. Декабрь 2010 используется как история для определения когорт.
  • Оборот после отмен не равен прибыли; расходы для ROI отсутствуют.
Как воспроизвести расчёты

Для расчётов нужен Python 3.11+. В репозитории: python -m pip install -r requirements.txt, затем python analyze.py. В общем архиве минимальные зависимости находятся в requirements-core.txt. Скрипт загрузит UCI, построит SQLite-базу, CSV/JSON и выполнит контрольные проверки. build_powerbi.py обновляет встроенные снимки PBIP. Подробности — в README.
