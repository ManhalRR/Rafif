# Рафиф Алшауи · Data Analytics

**[Открыть портфолио](https://manhalrr.github.io/Rafif/)** · [Интерактивный анализ](https://manhalrr.github.io/Rafif/analytics.html) · [Excel](downloads/Retail_Analytics.xlsx) · [Полный комплект](downloads/Rafif_Analytics_Source.zip)

Анализ продаж и повторных покупок на UCI Online Retail, плюс A/B-анализ на синтетических данных. SQL и Python выполняют расчёты, Excel позволяет проверить формулы и фильтры. Проект Power BI опубликован в редактируемом формате PBIP.

## Быстрая проверка

1. В [дашборде](https://manhalrr.github.io/Rafif/analytics.html) выберите Германию и январь–март 2011: оборот после отмен **£39 590,69**, **82 заказа**.
2. В [Excel](downloads/Retail_Analytics.xlsx) выберите Германию: за весь период январь–ноябрь — **£199 330,67**, **410 заказов**. Лист «Когорты» содержит формулы и незаполненные будущие окна.
3. Просмотрите [SQL с CTE и оконными функциями](sql/01_monthly_sales.sql), [расчёт когорт](sql/03_cohort_retention.sql), [Python](analyze.py) и [протокол 28 проверок](results/validation.json).

## Задачи, результаты и следующие решения

| Вопрос | Результат | Интерпретация |
|---|---|---|
| Как распределён оборот? | Январь–ноябрь 2011: £8 587 247,02 после отмен; 17 582 заказа с продажами. Доля Великобритании — 83,2%. | Разделять анализ основного рынка и остальных стран: общий тренд не характеризует каждую страну. |
| Какая доля клиентов покупает снова? | Взвешенное M1 январских–октябрьских когорт — 19,94%. | Сравнивать зрелые когорты и учитывать неизвестные CustomerID; без ориентира нельзя объявить удержание низким. |
| Что происходит с отменами? | £616 898,70; отношение к положительным продажам — 6,70%. | Для анализа причин нужна связь отмен с исходными заказами. Это не доля возвратов заказов и не прибыль. |
| Улучшился ли вариант B? | На синтетических данных: конверсия +1,35 п.п., 95% ДИ +0,53…+2,17 п.п. | Эффект выручки на пользователя не подтверждён. Раскатка и коммерческий эффект не заявляются. |

## Воспроизведение расчётов

Нужен **Python 3.11+**. Установка Power BI или Excel для расчётного конвейера не требуется.

```bash
git clone https://github.com/ManhalRR/Rafif.git
cd Rafif
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python analyze.py
```

Первый запуск загружает официальный XLSX UCI. SHA-256 проверяется до расчётов; неожиданный источник останавливает выполнение. Скрипт создаёт `data/portfolio.sqlite`, синтетический CSV и `results/`. SQL выполняется в SQLite; переносимость синтаксиса на PostgreSQL/Greenplum не заявляется. Опубликованные результаты можно сверить с локальной пересборкой.

Конвейер: **XLSX → нормализация → SQLite / SQL → независимая сверка pandas → CSV / JSON → отчётность**.

В полном архиве дополнительно находятся генераторы PDF/HTML, Excel и PBIP, исходники модели и готовые отчёты. Минимальные зависимости там — `requirements-core.txt`; PDF-генерация использует Windows Arial и описана в README. Генератор Excel требует Node.js и `@oai/artifact-tool`; готовая книга открывается без него.

## Данные и определения

- Денежные суммы хранятся в целых пенсах. Сумма строки округляется один раз, half-to-even.
- Продажа: положительные количество и цена, номер счёта без `C`. Отмена: отрицательное количество, положительная цена, номер с `C`.
- Точные повторы сохранены: надёжного ID строки нет. Чувствительность результата к их удалению — £18 540,62 за отчётный период.
- Пропуски CustomerID исключены только из когорт, но не из денежных метрик. Их 24,9% исходных строк.
- Декабрь 2011 неполный и исключён. Декабрь 2010 служит историей для когорт. Первая наблюдаемая покупка не обязательно первая покупка клиента за всё время.
- M1 — покупка в следующем календарном месяце. Незавершённые окна — `NULL`, не ноль. Взвешенный показатель использует суммы клиентов, не среднее процентов.
- A/B-набор: 24 000 участников, seed 20261027, ITT, завершённое семидневное окно, SRM, z-test, Newcombe/Wilson CI. RPU — дополнительная метрика с нормальным приближением CI.
