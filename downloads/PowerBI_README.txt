POWER BI · RETAIL ANALYTICS
Рафиф Алшауи · Портфолио аналитика данных

ОТКРЫТИЕ
1. Распакуйте весь ZIP, сохранив структуру папок.
2. Откройте Retail_Analytics.pbip в актуальном Power BI Desktop.
3. Нажмите «Обновить / Refresh», чтобы загрузить встроенные данные в модель.
   Доступ к файлам компьютера, сервисам и учётным записям не нужен.
4. Три страницы: продажи, география, удержание. В первых двух работают
   срезы страны и месяца. Страница удержания имеет фиксированный охват.

ФОРМАТ И СТАТУС ПРОВЕРКИ
Это редактируемый проект PBIP: отчёт PBIR и семантическая модель TMSL.
Исходные определения JSON проверены по официальным схемам Microsoft.
Контрольные значения сверены с SQL и Python. Power BI Desktop в среде
сборки не установлен: запуск, рендеринг визуализаций и DAX-исполнение
в Desktop ещё не проверены. Файл PBIX в комплект не входит.

МОДЕЛЬ
Sales: 269 строк; одна строка на страну и месяц, январь–ноябрь 2011.
Countries и Calendar — измерения, фильтрация в одну сторону к Sales.
Cohorts — отдельная таблица M0–M5 по всем странам. Не соединена с Sales,
чтобы фильтр страны не создавал неверное впечатление о фильтрации когорт.
Денежные суммы — целые пенсы. Визуальные меры переводят их в GBP.
Power Query M содержит встроенные CSV-снимки. Чтобы обновить снимок:
python analyze.py, затем python build_powerbi.py из родительской папки.

ИСТОЧНИК И ОГРАНИЧЕНИЯ
Chen, D. (2015). Online Retail. UCI Machine Learning Repository.
https://doi.org/10.24432/C5BW33 · лицензия CC BY 4.0.
Открытые исторические данные; не данные работодателя.
Исходно 541 909 строк; строки без положительной цены исключены.
Пропуски CustomerID исключены только из когорт, не из продаж.
Совпадающие строки сохранены: в источнике нет надёжного ID строки.
Неполный декабрь 2011 исключён. Оборот не равен прибыли.
Подробности, SQL, проверки и полный конвейер — в общем архиве портфолио.
